# Academic Certificate Verification DApp

A decentralized application (DApp) built on the Ethereum blockchain to issue, manage, and verify academic certificates securely. This system ensures the authenticity of academic records, prevents credential fraud, and provides an easy way for employers to verify candidates' credentials via the blockchain.

## Features

- **Admin Portal**: A centralized dashboard to register and manage authorized universities.
- **University Portal**: Allows registered universities to securely add students and issue verifiable blockchain certificates.
- **Public Verification**: Anyone can verify the authenticity of a certificate using its unique Certificate ID or by scanning a generated QR code.
- **Tamper-Proof Data**: Employs Keccak256 hashing and IPFS concepts for secure, immutable record-keeping.
- **Performance Evaluation**: Built-in benchmarking scripts to evaluate gas costs and smart contract execution time.

## Project Structure

This repository consists of three main components:

1. **`/blockchain`**: Contains the Hardhat project, Solidity smart contracts (`CertificateManager.sol`), and deployment/benchmarking scripts.
2. **`/frontend`**: Contains the Vanilla JS + Vite frontend web application, which interacts directly with the smart contract using Ethers.js.
3. **`/docs`**: Contains performance reports and evaluation metrics of the smart contract operations.

## Tech Stack

- **Smart Contracts**: Solidity, Hardhat, Ethers.js (v6)
- **Frontend**: HTML5, Vanilla JavaScript, CSS, Vite
- **Libraries**: `qrcode`, `ethers`

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [MetaMask](https://metamask.io/) Extension installed in your browser

### 1. Smart Contract Setup (Local Network)

Open a terminal and navigate to the `blockchain` directory:

```bash
cd blockchain
npm install
```

Start the local Hardhat blockchain network:

```bash
npx hardhat node
```

In a **second terminal**, deploy the smart contract to the local network:

```bash
cd blockchain
npx hardhat run scripts/deploy.js --network localhost
```

> **Note**: The deployment script automatically updates the `contract-config.json` file in the frontend folder with the new contract address and ABI.

### 2. Frontend Setup

Open a **third terminal** and navigate to the `frontend` directory:

```bash
cd frontend
npm install
```

Start the Vite development server:

```bash
npm run dev
```

The application will now be accessible at `http://localhost:5173`.

### 3. MetaMask Configuration

1. Open your MetaMask extension and add/connect to your **Localhost 8545** network (RPC URL: `http://127.0.0.1:8545`, Chain ID: `31337`).
2. Import one of the private keys generated by the `hardhat node` into MetaMask. 
3. **Account #0** will act as the **System Administrator** (the wallet that deployed the contract).

> **Troubleshooting Tip**: If you restart the Hardhat node, MetaMask might throw a "Nonce too high" error. To fix this, go to MetaMask Settings > Advanced > **Clear activity and nonce data** (or "Reset Account").

## Usage Guide

1. **Admin Functions**: Connect MetaMask with the Admin Account. Navigate to the **Admin Portal** to register a new University by providing their details and Ethereum wallet address.
2. **University Functions**: Switch your MetaMask account to the newly registered University's wallet address. Navigate to the **University Portal** to register students and issue certificates to them.
3. **Verification**: Navigate to the **Verification** page. Anyone can verify a certificate by simply entering the Certificate ID. The DApp will fetch and validate the record from the blockchain.

## Performance Benchmarking

To test the performance and gas costs of the smart contract functions, you can run the benchmarking script:

```bash
cd blockchain
npx hardhat run scripts/performance-test.js --network localhost
```

The comprehensive performance evaluation is available in the [`docs/performance-report.md`](./docs/performance-report.md) file.
